# Система логина и регистрации

## Демо-аккаунты для тестирования

При первом запуске приложения автоматически создаются следующие демо-аккаунты:

### Аккаунт 1
- **Email:** anna@example.com
- **Пароль:** 123456
- **Имя:** Анна Петрова

### Аккаунт 2
- **Email:** ivan@example.com
- **Пароль:** 123456
- **Имя:** Иван Сидоров

## Функциональность

### Вход в аккаунт
1. Нажмите на кнопку "Войти в личный кабинет" в заголовке
2. Появится модальное окно входа
3. Введите email и пароль
4. Нажмите кнопку "Войти"
5. После успешного входа текст кнопки изменится на ваше имя

### Профиль пользователя
После входа:
- Нажмите на ваше имя в заголовке
- Появится меню профиля с опциями:
  - Мои заказы
  - Мое избранное
  - Настройки личных данных
  - Выход

### Восстановление пароля
1. В модальном окне входа нажмите на ссылку "Восстановить пароль?"
2. Вас перенесет на страницу восстановления пароля
3. Введите свой email
4. Нажмите кнопку "Восстановить пароль"
5. Появится страница подтверждения

### Регистрация новоо аккаунта
1. В модальном окне входа нажмите на текст "Нет аккаунта? Зарегистрироваться"
2. Вас перенесет на страницу регистрации
3. Заполните поля:
   - Имя
   - Email
   - Пароль
   - Повторите пароль
4. Нажмите кнопку "Зарегистрироваться"
5. Аккаунт создан, вы будете перенесены на главную

## Технические детали

### Хранилище данных
- Данные пользователей хранятся в localStorage браузера
- `users` - массив всех зарегистрированных пользователей
- `currentUser` - информация текущего вошедшего пользователя

### Структура пользователя
```javascript
{
  id: "уникальный ID",
  name: "Имя пользователя",
  email: "email@example.com",
  password: "пароль",
  createdAt: "ISO дата создания"
}
```

## Страницы

### /recovery-password
Страница восстановления пароля с одним полем для ввода email

### /thank-you
Страница благодарности, отображается после восстановления пароля

### /registration
Страница регистрации с полями для имени, email, пароля и подтверждения пароля

## Анимации

- Модальные окна появляются с плавной анимацией масштабирования и прозрачности
- Кнопки имеют эффект hover и tap
- Счетчик корзины появляется с пружинящей анимацией
- Элементы профиля анимируются при наведении

## Корзина

В заголовке отображается счетчик товаров в корзине:
- При `cartCount > 0` появляется красный значок с числом товаров
- Счетчик анимируется при появлении

## Мобильная версия

Полная поддержка мобильной версии:
- Все функции работают на сенсорных устройствах
- Профиль доступен через меню бургер
- Счетчик корзины отображается с правой стороны
