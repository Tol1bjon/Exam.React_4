# Структура файлов системы аутентификации

## Новые файлы добавлены:

### Контекст аутентификации
- **src/context/AuthContext.jsx** - React Context для управления состоянием аутентификации
  - Функции: register, login, resetPassword, logout
  - Хранит: user, loading, cartCount
  - Использует localStorage для сохранения данных

### Страницы
- **src/Pages/Recovery_Password/Recovery_Password.jsx** - Страница восстановления пароля
  - Поле для ввода email
  - Валидация email
  - Кнопка "Восстановить пароль"
  - Навигация на /thank-you после успеха

- **src/Pages/Recovery_Password/ThankYou.jsx** - Страница благодарности
  - Подтверждение отправки инструкций
  - Кнопка возврата на главную

- **src/Pages/Recovery_Password/Registration.jsx** - Страница регистрации
  - Поля: имя, email, пароль, подтверждение пароля
  - Валидация всех полей
  - Проверка совпадения паролей
  - Проверка уникальности email
  - Экран успеха с анимацией

### Утилиты
- **src/utils/initializeData.js** - Инициализация демо-аккаунтов
  - Создает 2 тестовых аккаунта при первом запуске
  - Сохраняет в localStorage

### Обновленные файлы
- **src/App.jsx** - Добавлены новые маршруты и AuthProvider
- **src/Layout/Header.jsx** - Полностью переписан с поддержкой аутентификации
  - Логин/регистрация модалка
  - Профиль пользователя
  - Счетчик корзины
  - Поддержка мобильной версии

## Маршруты приложения

Новые маршруты:
- `/recovery-password` - Страница восстановления пароля
- `/thank-you` - Страница благодарности
- `/registration` - Страница регистрации

Существующие маршруты остались без изменений.

## LocalStorage ключи

- `users` - Массив всех пользователей
- `currentUser` - Текущий вошедший пользователь
- `resetEmail` - Email для восстановления пароля (временно)
- `resetPassword` - Новый пароль (временно)

## Потоки данных

### Регистрация
1. Пользователь заполняет форму
2. Валидация на клиенте
3. Проверка уникальности email
4. Создание нового пользователя
5. Сохранение в localStorage
6. Автоматический вход
7. Экран успеха

### Вход
1. Пользователь вводит email/password
2. Поиск пользователя в localStorage
3. Проверка пароля
4. Сохранение currentUser в localStorage
5. Обновление UI

### Восстановление пароля
1. Пользователь вводит email
2. Поиск пользователя
3. Генерация нового пароля
4. Сохранение в localStorage
5. Редирект на /thank-you

### Выход
1. Удаление currentUser из localStorage
2. Обновление UI

## Анимации

Используется библиотека Framer Motion для всех анимаций:
- Модалки появляются/исчезают с scale и opacity
- Кнопки имеют hover/tap эффекты
- Счетчики появляются с spring анимацией
- Меню элементы анимируются при наведении
