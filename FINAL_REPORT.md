- `users` - Массив всех пользователей (JSON)
- `currentUser` - Текущий вошедший пользователь (JSON)

## 📝 Примеры использования

### Вход в систему
```javascript
// В компоненте
const { login } = useContext(AuthContext);
const result = login('anna@example.com', '123456');
if (result.success) {
  // Пользователь вошел
}
```

### Регистрация
```javascript
const { register } = useContext(AuthContext);
const result = register({
  name: 'John Doe',
  email: 'john@example.com',
  password: '123456'
});
```

### Получение текущего пользователя
```javascript
const { user } = useContext(AuthContext);
if (user) {
  console.log(user.name); // "Анна Петрова"
}
```

### Выход
```javascript
const { logout } = useContext(AuthContext);
logout();
```

## 🧪 Как протестировать

### 1. Вход через демо-аккаунт
1. Запустите приложение
2. Нажмите "Войти в личный кабинет"
3. Email: `anna@example.com`, Пароль: `123456`
4. Нажмите "Войти"
5. Текст должен измениться на "Анна Петрова"

### 2. Профиль
1. Нажмите на "Анна Петрова"
2. Появится меню с опциями
3. Нажмите "Выход"
4. Вернетесь в начальное состояние

### 3. Регистрация
1. Нажмите "Войти в личный кабинет"
2. Нажмите "Нет аккаунта? Зарегистрироваться"
3. Заполните форму
4. Нажмите "Зарегистрироваться"
5. Появится экран успеха

### 4. Восстановление пароля
1. Нажмите "Войти в личный кабинет"
2. Нажмите "Восстановить пароль?"
3. Введите email
4. Нажмите "Восстановить пароль"
5. Перейдет на страницу "Спасибо"

### 5. Мобильная версия
1. Откройте DevTools (F12)
2. Включите Responsive Design Mode (Ctrl+Shift+M)
3. Выберите мобильное устройство
4. Все функции должны работать на сенсорных экранах
